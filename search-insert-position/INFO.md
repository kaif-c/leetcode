# Search Insert Position

## Difficulty: Easy

**Description**:

Given a sorted array and an integer, find the index of the integer or the posistion where it should be if the integer isn't present
You must write an algorithm with O(log n) runtime complexity

**Constraints**:

- 1 <= nums.length <= 10^4
- -10^4 <= nums[i] <= 10^4
- nums contains distinct values sorted in ascending order.
- -10^4 <= target <= 10^4
